# Experiência de primeiro projeto
Inicio de aprendizagem sobre Java(aprendizado solo), atividade do 1° semestre das aulas da oficina do NAAHS Altas Habilidades.

Projeto com fim educacional com uma ideia de exercício sobre o que poderíamos desenvolver, surgindo a ideia de desenvolver um RPG com base na criatividade.
Esse foi meu primeiro projeto utilizando os primeiros conceitos que aprendi com a linguagem Java, passando horas em erros de fechamento de chaves e sem saber porque o texto estava repetindo infinitamente ou muitos erros iniciais. 
Com todo esse projeto, consegui desenvolver melhor com a lógica de programação e ver como a máquina pensa. Com isso, mesmo sendo um projeto inicial, consegui ter bons resultados com novos conceitos de java.

# Como o jogo funciona

Um sistema básico por linhas do terminal, tendo um personagem(Era para ter dois) principal, o Guerreiro. 
Ele mora em uma vila, mas esta vila foi atacada por vilões. É baseado em sistemas de turnos, tendo um para o guerreiro e outro para o inimigo. No turno do guerreiro, ele tem opções do que ele pode fazer, como atacar, defender ou tomar poções, mas, entretanto, existe um sistema de dados de mesa de RPG, se cair em um certo número que é abaixo do esperado, sendo o Guerreiro ou Inimigo, ele sofrerá a devida consequência.

Fiz um sistema de escolhas no final, tendo seguimentos de linhas conforme cada opção, além de um final que depende totalmente da sorte para decidir o próximo passo, o fim ou a vitória...

##Jogo funciona somente com JDK 17.0.19 instalado
