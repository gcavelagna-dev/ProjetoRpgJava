# Experiência de primeiro projeto
Inicio de aprendizagem sobre Java(aprendizado solo), atividade do 1° semestre das aulas da oficina do NAAHS Altas Habilidades.

Projeto com fim educacional com uma ideia de exercício sobre o que poderíamos desenvolver, surgindo a ideia de desenvolver um RPG com base na criatividade.
Esse foi meu primeiro projeto utilizando os primeiros conceitos que aprendi com a linguagem Java, passando horas em erros de fechamento de chaves, laços de repetições infinitos e muitos outros. 
Com todo esse projeto, consegui desenvolver melhor com a lógica de programação e ver como uma máquina pensa. Com isso, mesmo sendo um projeto inicial, consegui ter bons resultados com novos conceitos de java.

# Como o jogo funciona

Um sistema básico por linhas do terminal, tendo um personagem(Era para ser dois) principal, o Guerreiro. 
Ele mora em uma vila que foi ataca por monstros e vilões. É baseado em sistemas de turnos, tendo um para o guerreiro e outro para o inimigo. No turno do guerreiro, ele tem opções do que ele pode fazer, como atacar, defender ou tomar poções.
Mas, entretanto, existe um **sistema de dados de mesa de RPG**, se cair em um certo número que é abaixo do esperado, sendo o Guerreiro ou Inimigo, ele sofrerá a devida consequência.

No final há um caminho onde pode se dissolver conforme as escolhas, tenha cuidado.
